# 投资框架总览

> 市场很热闹，纪律最好别请假。

## 摘要

投资不是预测，而是决策框架。这个框架的核心是三件事：**买什么**（价值分析）、**什么时候买**（周期定位）、**怎么买**（风险管理）。不是投资建议，而是避免自己胡来的纪律。

---

## 一、投资哲学：三个不变的原则

1. **价格 vs 价值**——没有绝对好或坏的资产，只有价格相对价值的高低。
2. **生存优先**——保住本金比追求收益更重要。避免全盘皆输。
3. **耐心复利**——钱是坐着等来的。慢慢变富，才能细细体会其中的美妙。

---

## 二、决策检查清单

每次投资前，依次追问：

| 维度 | 问题 |
|------|------|
| 价值 | 内在价值是多少？用什么方法估算？ |
| 价格 | 当前价格有多少折让？安全边际够吗？ |
| 能力圈 | 我真的理解这个生意吗？能看懂十年后吗？ |
| 风险 | 最坏情况是什么？能承受吗？ |
| 机会成本 | 比我现有持仓更好吗？ |
| 持有期 | 能持有五年以上吗？ |

## 四、持仓逻辑框架

### 选股核心指标

| 指标 | 意义 | 参考标准 |
|------|------|---------|
| ROE 趋势 | 持续高 ROE 说明有护城河 | > 12% 且稳定或上升 |
| 自由现金流 | 赚的是真金白银，不是纸面利润 | 持续为正，且趋势向上 |
| 行业竞争格局 | 寡头优于完全竞争 | 行业集中度提升中 |
| 管理层质量 | 诚信、能力、股东导向 | 过往承诺兑现率 |

### 风险边界

| 维度 | 纪律 |
|------|------|
| 单一持仓 | 上限不超过总资产的 25-30% |
| 行业集中度 | 同一行业不超过 40% |
| 杠杆 | 不使用杠杆——"不要做可能让你全盘皆输的事情" |
| 现金储备 | 始终保留一定比例现金，等待"被迫卖出"的机会 |

### 跟踪清单

- 季度财报：营收增速、毛利率变化、现金流情况
- 行业政策：监管动向、竞争格局变化
- 估值分位数：当前估值在历史中的位置（低于 30% 分位为低估区域）
- 护城河变化：品牌、网络效应、成本优势、转换成本是否在加强还是削弱

> 记录每笔交易的买入逻辑，定期回顾验证——这是最好的投资学习方式。
