# 投资框架总览

> 市场很热闹，纪律最好别请假。

## 摘要

投资不是预测，而是决策框架。这个框架的核心是三件事：**买什么**（价值分析）、**什么时候买**（周期定位）、**怎么买**（风险管理）。不是投资建议，而是避免自己胡来的纪律。

---

## 一、投资哲学：三个不变的原则

1. **价格 vs 价值**——没有 inherently 好或坏的资产，只有价格相对价值的高低。
2. **生存优先**——保住本金比追求收益更重要。避免全盘皆输。
3. **耐心复利**——钱是坐着等来的。慢慢变富，才能细细体会其中的美妙。

---

## 二、决策检查清单

每次投资前，依次追问：

| 维度 | 问题 |
|------|------|
| 价值 | 内在价值是多少？用什么方法估算？ |
| 价格 | 当前价格有多少折让？安全边际够吗？ |
| 能力圈 | 我真的理解这个生意吗？能看懂十年后吗？ |
| 风险 | 最坏情况是什么？能承受吗？ |
| 机会成本 | 比我现有持仓更好吗？ |
| 持有期 | 能持有五年以上吗？ |
