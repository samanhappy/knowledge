## 为什么做这个知识库

这个仓库不是单纯的博客，而是一套 **个人知识生产系统**：

- `raw/` 存放原始资料、摘录、图片、视频与链接
- `docs/` 存放经过 AI 编译后的知识文章与索引页面
- GitHub 负责版本记录与远程托管
- VitePress 负责把知识库发布成可直接浏览的网站

## 当前分类

- [成长](/growth/)：习惯、反思、学习法、长期主义
- [生活](/life/)：居家系统、效率、健康、关系与体验
- [技术](/tech/)：开发、AI 工作流、工程实践、工具链
- [投资](/invest/)：框架、备忘、研究、风险管理

## 推荐使用方式

1. 把文章、论文、截图、网页摘录先放进 `raw/`
2. 让 AI 帮你整理成 Markdown 草稿
3. 将整理后的内容归档到对应主题目录
4. 定期维护索引页、专题页、近期更新页

> 目标不是“写更多”，而是“让知识越来越会自己长出来”。很科幻，但足够实用。
